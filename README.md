# 📊 ML Based Demand Forecasting

A machine learning-based sales demand forecasting project developed during my R&D internship at **Jadson Technologies Pvt. Ltd., Coimbatore**.

The project analyzes historical e-commerce sales data to identify trends, monthly and quarterly patterns, and sales volatility. **Linear Regression** was implemented to forecast future sales and support demand and inventory planning.

- Prediction accuracy may vary with real-world fluctuations.
